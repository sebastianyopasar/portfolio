# Portfolio V4.1 — Readability polish

This is a full experimental project copy; it does not affect the live portfolio.

## Changes
- Experience (Work) displays Corporate Facility Supply and RO, Horatio only, in English, French and Spanish. Education and certificates are unchanged.
- Reduced visual crowding in the oversized Montserrat headlines: gentler letter spacing, more line-height, and slightly refined headline sizing across the Home.

- The layout, case study pages, navigation, project imagery, and interactions are unchanged.

## Run (from the folder containing package.json)

```powershell
npm ci
npm run dev
```

Open http://localhost:3000. Before publishing, run `npm run build` on your Windows PC.
